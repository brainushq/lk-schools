# Canonical dataset

`schools.json` and `districts.json` are the single source of truth for both
the npm and PyPI packages. `scripts/sync-data.mjs` copies these into each
package's source tree at build time — never edit the copies under
`packages/*/`, only these files.

## Building from official MoE data

`data/schools.json` is generated by `scripts/build-from-moe.py` from the
Ministry of Education's 2024 Educational Statistics school lists
(`data/raw/moe-2024/*.csv`, originally the Excel files linked at
https://dmb.moe.gov.lk/showStat2024.php — List of National School 2024 plus
the 9 provincial lists). The dataset is the complete official government
school list (10,076 schools) with census numbers, addresses, zones,
education divisions and MoE A/L type. Private rows from
`data/raw/legacy-schools.json` (a frozen snapshot of the old BrainUs
dataset) are kept as-is since they are real schools outside the government
list.

Re-run with: `python3 scripts/build-from-moe.py` (stdlib only, idempotent).
The raw CSVs and the legacy snapshot are committed for provenance.

## Schema

### `districts.json`

| field      | type   | notes                                     |
|------------|--------|--------------------------------------------|
| `name`     | string | e.g. "Jaffna" — the district's own key, no separate id |
| `province` | string | e.g. "Northern"                            |

### `schools.json`

| field               | type           | notes                                                                 |
|---------------------|----------------|-------------------------------------------------------------------------|
| `id`                | string         | slug owned by this dataset, e.g. `"trinity-college-kandy"` — not a database ID, contributors mint their own |
| `name`              | string         |                                                                          |
| `district`          | string         | must match a `name` in `districts.json` — checked in CI                 |
| `type`              | string \| null | `provincial` \| `national` \| `international` \| `private`              |
| `censusNo`          | string \| null | official MoE census number, unique per government school                |
| `moeType`           | string \| null | MoE grade-span classification — see table below                         |
| `address`           | string \| null | MoE address (government rows)                                           |
| `zone`              | string \| null | MoE education zone                                                      |
| `educationDivision` | string \| null | MoE education division                                                  |
| `source`            | string \| null | e.g. `"moe-gov-2024"` or `"wikipedia"` — required for new rows            |

`province` is not stored on schools — both packages derive it from `district`
by joining against `districts.json` at load time, so a district's province
only ever needs correcting in one place.

New contributions must set `source`. Rows missing it are treated as
unverified and excluded from release builds once that check is added to CI.

## MoE school type (`moeType`)

The Ministry classifies government schools by the highest grade span they
offer. This is useful for targeting (e.g. A/L-focused products only care
about `1AB` and `1C` schools).

| moeType | Meaning                                                                                                    | Typical grade span              |
|---------|------------------------------------------------------------------------------------------------------------|----------------------------------|
| `1AB`   | Offers G.C.E. A/L Science streams (Biological and/or Physical Science).                                    | Grade 1–13 or 6–13               |
| `1C`    | Offers G.C.E. A/L streams other than Science (Arts, Commerce, Technology, Vocational).                     | Grade 1–13 or 6–13               |
| `Type2` | Goes up to G.C.E. O/L but does not offer A/L classes.                                                      | Grade 1–11, 6–11, or 1–9         |
| `Type3` | Primary/junior school that does not reach O/L level.                                                       | Grade 1–5, 1–8, or up to 8       |

Only government rows carry `moeType`; private/international rows are `null`.
